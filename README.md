# Ecommerce-analytics-engineering

## Objective

Build an end-to-end analytics engineering pipeline using Snowflake, dbt, and Power BI.

## Project Structure

* `data/` — Raw source datasets
* `snowflake/` — SQL scripts for warehouse setup
* `dbt_project/` — Data transformation models and tests
* `powerbi/` — Business intelligence dashboard

## Data Sources

Olist Brazilian E-Commerce Dataset

## Business Questions

1. What are the monthly revenue and order trends?
2. Which products and categories generate the most revenue?
3. Who are the top 10 customers by spending?
4. What percentage of orders are cancelled?
5. How does average order value change monthly?

## Technology Stack

* Snowflake
* dbt
* SQL
* Git and GitHub
* Power BI
